# The House — dedicated room scenes

The house overview now transitions into separately illustrated 1672×941 room close-ups.

- `assets/rooms/maya.webp` — book wall, visitor notes, life updates, daily photo
- `assets/rooms/jay.webp` — movie wall, vinyl console, visitor notes, daily photo
- `assets/rooms/lounge.webp` — TV, shared gallery, daily photo, group messages

The camera zooms the original house before crossfading into crisp room-specific artwork. Object interactions and editable demo lists remain, but old cartoon characters and walking controls have been disabled. This is a static-browser prototype, not real multiplayer.

Run: `python3 -m http.server 3000`, or deploy from `main` with Vercel's static preset.
